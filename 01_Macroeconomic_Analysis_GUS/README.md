# Project 1: Macroeconomic Analysis (GUS BDL API)

## Overview
This project focuses on extracting, transforming, and loading (ETL) regional macroeconomic data from the Statistics Poland (GUS) public API. The goal is to provide a comprehensive dataset for analyzing unemployment, average salaries, investments, and demographic metrics across Polish regions (voivodeships and powiats).

## Business Objectives
- Automate the extraction of statistical data across multiple years (2018-2024).
- Process nested JSON API responses into flat, analytical structures using Python and Pandas.
- Prepare a clean, "Gold" layer dataset ready for business dashboards (Power BI) and relational databases.

## Project Structure & Files

This directory contains the entire ETL pipeline for the macroeconomic project:

- **`Zadanie_Dodatkowe.md`** 
  Contains the detailed business requirements, project guidelines, and expected analytical outcomes. (Business Analyst Briefing)

- **`skrypt_api.py`** 
  The Data Extraction (Bronze Layer) script. It dynamically loops through a predefined list of KPI IDs, connects to the official GUS REST API, handles pagination and rate-limiting (HTTP 429), and saves the raw data into JSON files.

- **`dane/` (Directory)**
  The local storage for the raw, extracted JSON files generated by `skrypt_api.py`. This acts as our Bronze data lake.

- **`skrypt_pandas.py`** *(In Progress)* 
  The Data Transformation (Silver Layer) script. It will dynamically load all JSON files from the `dane/` folder, flatten their nested structures (`pd.json_normalize`), and join them into a single, comprehensive Master Fact Table.

- **`skrypt-sql.py`** 
  The Data Loading (Gold Layer) script. Designed to insert the structured data into a PostgreSQL database, setting the foundation for the Star Schema architecture.

## Tech Stack
- **Python**: API interaction (`requests`), Data manipulation (`pandas`), File handling (`glob`, `json`)
- **PostgreSQL**: Relational database for structured storage
- **Data Architecture**: Medallion Architecture (Bronze -> Silver -> Gold), Star Schema

## How to run
1. Execute `python skrypt_api.py` to fetch fresh data from the GUS API into the `dane/` folder.
2. (Soon) Execute `python skrypt_pandas.py` to aggregate the JSON files into a master CSV file for Power BI.
